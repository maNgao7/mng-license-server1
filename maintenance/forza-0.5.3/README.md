# Turkish Forza 0.5.3

Incremental source snapshot for the native game mod and launcher portrait delivery.
The Windows packages are built with the existing Forza and TikMnG release projects.

- P plays the staged countdown clip from its beginning. The BAŞLA label fits in the banner.
- The native engine mix remains audible when leaving the chase camera.
- Live race portraits use the shared cache and can arrive after the original event without applying its reward twice.
- Built-in test drivers use the TikMnG logo.

The preview ran with the same native DLL as the public ZIP. An isolated race verified countdown playback,
engine channels across camera changes, portrait delivery through the local bridge and a clean next grid.
A separate TikTok test observed and downloaded real portraits. The two tests were run separately.
The public ZIP upgrade from 0.5.2 was verified with the game library after reopening it.
