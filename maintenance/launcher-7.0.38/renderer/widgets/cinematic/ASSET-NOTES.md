# Cinematic assets

- Three.js 0.180.0, vendored from its published npm package. The unmodified MIT
  license is in `THREE-LICENSE.txt`; addon imports were changed to local paths.
- The bundled Helvetiker font license is in `FONT-LICENSE.txt`.
- `assets/botanical-crown.png` and `assets/inferno-crown.png` were generated for
  this TikMnG design review using the built-in image generation tool on
  2026-11-05. They are original transparent ornamental textures, not assets
  downloaded from a competing application.
- Botanical direction: photoreal CGI roses, platinum and gold filigree around
  an empty transparent central aperture. Inferno direction: bronze lion
  ornament, dark metal, gold highlights and an empty central aperture.
- `assets/pk-creatures-atlas.png` (dragon, wolf, lion, serpent),
  `assets/pk-gloves-atlas.png`, and `assets/jars-atlas-v2.png` were created using
  the built-in image generation tool on 2026-11-06. Brief: detailed CGI creature
  cutouts, opposing leather boxing gloves, and four transparent glass containers.
  The v2 jars remove the milky rectangular haze from the first atlas. Original
  v1 assets are retained rather than overwritten.
- PK typography, particles and premium scene surfaces are live Three.js meshes.
  Creature and glove art uses textured planes with animation/deformation; these
  are not skeletal or fully modeled 3D characters. Ornamental image planes
  complement the geometry.
- Catalog posters are captures of the actual preview URLs, generated by
  `tools/render-widget-posters.cjs`. No poster is a substitute for its widget.
- Keep the static dispatcher allowlist, the publisher bridge and the server
  relay allowlist in sync before publishing. State/profile/event endpoints
  remain keyed; only reviewed static rendering assets are public cacheable.
- This directory contains no credentials, user profiles or event history.
