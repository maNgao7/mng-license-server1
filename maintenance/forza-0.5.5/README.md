# Turkish Forza 0.5.5

The launcher remains the only live session owner. The existing loopback publisher and native game bridge deliver likes and gift credits. A like without a message ID uses its room ID with the room total or message time for replay protection. Only the per-viewer count earns speed. Incomplete like thresholds carry into the next race without automatically recreating the grid.

Race portraits reuse the existing shared cache and TikTok profile sources. Priority retries deliver a late portrait without changing race credit. The portrait is cached under the game data directory at control/live/portraits. Race records still use the existing versioned results store.

Settings are saved in the game's control/settings.json. The settings overlay queues a serialized atomic write, and the camera and native race stay active. At the third finish the main camera blends from its current position, rotation and field of view to the winner. The winner receives the existing 3D crown and a circular identity badge.

The incremental snapshots in this directory accompany the installed Windows packages. QA scripts run from the full native project with its Steam support files, assets and test dependencies.
