# TikMnG Management Preview - 22 October 2026

Private preview 6.5.17. This is not a stable launcher release. Stable profiles,
installed games and saved game gift mappings are not changed. This report
supersedes earlier preview acceptance summaries.

## Speech

- Removed unused Azure/account/central-service controls from the speech page.
  Actual speakers are listed on the right with select, test, ready/download and
  repair controls. No pitch preset is presented as a different person.
- Ten distinct synthetic Turkish reference speakers: Ece, Mert, Ada, Efe, Derya,
  Arda, Neva, Bora, Beste and Usta. All ten exact URIs produced actual WAV files
  through packaged Electron, with separate output hashes. Listening acceptance
  and pronunciation checks remain with the user.
- Two small downloadable Turkish engines, Okur and EMA, plus installed Windows
  Turkish voices remain available for lower-latency reading.
- The optional natural-voice pack downloads independently from launcher/game
  updates. Download: 3,676,920,620 bytes. Unpacked model/runtime is approximately
  5.1 GB; installation also needs staging/cache space. Fixed hashes, resumable
  transfer, cancellation, bounded ZIP extraction and atomic activation are tested.
- A real installation from the verified local download cache took 84.286 seconds
  and exposed all ten voices. This test did not redownload model bytes.
- Standalone Python imports passed after relocation with networking blocked.
  The Turkish-only worker disables the upstream eager Chinese download, retains
  watermarking, bounds its queue, cancels owned workers and unloads when idle.
- CPU synthesis is not real time: short phrases took approximately 13-25 seconds
  warm and roughly 35 seconds on first load in packaged tests. Performance during
  a real game/broadcast and on a clean second PC is not accepted yet.
- Reference voices: PatientDesk AI, CC BY 4.0, the voices partition of
  cloud0day3/alania-synthetic-speech-tr. Chatterbox/model: Resemble AI, MIT.
  Attribution and dependency license notices are included. No named cartoon,
  child actor or regional-accent voices are supplied.

## Release Boundaries

- Actual gift playback in the user's TikTok LIVE Studio source is not verified.
  Health/HTTP 200 and browser playback do not guarantee every Live Studio version.
- The direct live connector is unofficial; uninterrupted TikTok availability
  cannot be guaranteed. No private TikFinity/TikOyun code or partner API was copied.
- The media archive remains local to this preview; the public media catalog is
  empty. Customer media distribution still requires publishing those assets.
- Per-file game updates are implemented and regression-tested, but current
  production catalog packages are full ZIPs. Publish their file manifests before
  claiming changed-files-only updates for those packages.
- A branded public hostname needs a real domain/DNS/TLS configuration. Working
  Render HTTPS addresses are preserved, not replaced with an invented hostname.
- A clean second-PC game/voice installation and user listening acceptance remain.
- The optional voice pack is separate from stable launcher releases. No stable
  launcher update, Render deployment or Google Drive upload is part of this run.
