# TikMnG Management Preview - 22 October 2026

Private local preview, version 6.5.17. Do not publish a stable update until the
user accepts this application. Existing stable profiles and games are untouched.
This report supersedes older test results in PREVIEW-ACCEPTANCE.md.

## Later Corrections In This Preview

- Removed the misleading male/female/child style selector. The UI now selects an
  actual speaker URI; natural pitch is used for the editor/test, not a fake child
  speaker made by shifting the same voice. Two offline packs remain available.
- Visual speech gift picker: 686 entries, ascending coin order, 60 per page,
  searchable by name/ID/coin. Gift grants last for the current session and changing
  the configured gift clears previous gift grants; follow grants remain separate.
- Audible video hover plays one tile at a time and stops on pointer leave.
- Viral Benim accumulates the same sender/gift contribution, keeps the incumbent
  on a tie and changes only when exceeded. Circular profile/gift flip with tiered
  effects has transparent broadcast background; previews have black background.
- Optional central speech relay is implemented and unconfigured/unpublished.
  Provider keys stay server-side; customers need no Azure account. 27 backend
  tests pass. Azure signup was deferred in favor of a local-model experiment.
- Latest launcher suite: 531 passed, zero failed/skipped. Installed package QA
  passed with audible hover, visual gift picker, 187 local/187 HTTPS responses,
  13 rendered widgets and a verified room on the supplied live test account.
- Chatterbox local experiment produced ten synthetic Turkish speaker samples;
  these are NOT yet launcher voices. See tools/voice-lab/README.md for sources,
  attribution, measured CPU latency and outstanding integration/release gates.

## Remaining Release Acceptance

- A real gift must be observed playing the assigned media in the user's actual
  TikTok LIVE Studio source. HTTP 200/browser playback does not prove acceptance
  by every Live Studio version. This check is NOT marked complete.
- Two trained offline speakers are installed; requested named cartoon/child
  actors are not supplied. More independent voices need suitable models/licenses.
- The 159-video archive is local to this preview. The public catalog currently
  contains no media assets; customer distribution still needs published files.
- Current production games use full ZIPs. Publish per-file assets/manifests before
  describing their updates as changed-files-only.
- A branded public hostname requires a real domain/DNS/TLS configuration. Do not
  replace the working HTTPS server hostname with an invented local domain.
- Every large game still needs download/launch acceptance on a clean second PC.
- Stable release, Render deployment and public distribution are not performed by
  the local preview installer.
